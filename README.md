## 🤝 How to Contribute

We welcome submissions for new tools, updated pricing, and corrections!

1. **Check the rules**: Read [`CONTRIBUTING.md`](CONTRIBUTING.md). We require verified public pricing, verified open-source licenses, and genuinely honest trade-offs in `what_youll_miss`.
2. **Edit `data/tools.yaml`**: Add your entry respecting the YAML schema.
3. **Rebuild the README**:
   ```bash
   python scripts/build_readme.py
   ```
4. **Open a Pull Request**: Submit your PR with a brief explanation.
