# cancel-your-saas 💸

> A fun, curated list of open-source alternatives to expensive SaaS tools, with honest trade-offs.

## Overview

Software-as-a-Service costs add up fast. This repository tracks high-quality, self-hostable open-source alternatives along with what you gain, what you save, and—crucially—**what you'll actually miss** when switching.

## Repository Structure

- [`data/tools.yaml`](data/tools.yaml): The single source of truth for all tools and pricing data.
- [`scripts/build_readme.py`](scripts/build_readme.py): Build script for formatting and updating documentation.
- [`docs/`](docs/): Assets and web files for the forthcoming GitHub Pages directory.
- [`CONTRIBUTING.md`](CONTRIBUTING.md): Guidelines for submitting new entries.

## Getting Started

To preview or generate the markdown table from the dataset:

```bash
python scripts/build_readme.py
```
